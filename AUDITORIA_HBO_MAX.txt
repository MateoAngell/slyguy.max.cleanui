1. IDIOMA - Español latino (es-419) NO funciona
================================================================================
Problema: El audio sale en inglés aunque se configuró es-419 en plugin.py.
El código actual en play() es:

  item.proxy_data['default_language'] = 'es-419'

CAUSA: proxy_data requiere que el proxy de slyguy entienda y SOPORTE
el campo 'default_language'. Si el manifest MPD no tiene audio en es-419,
el proxy lo ignora. Revisando el flujo:

1. plugin.play() setea proxy_data['default_language'] = 'es-419'
2. El proxy (script.module.slyguy) procesa el MPD
3. Si el MPD tiene audio en es-419, debería seleccionarlo
4. Si NO tiene es-419, cae al default (inglés)

SOLUCIÓN PROPUESTA (a verificar):
- En play(), imprimir los idiomas de audio disponibles del manifest
- El proxy_data['default_language'] podría llamarse distinto (verify en slyguy)
- Alternativa: pasar 'es-419' como language en la URL del manifest

2. RENDIMIENTO - Interfaz lenta
================================================================================
Síntomas: Navegación lenta comparada con Disney+. Tarda en cargar rails.

CAUSAS IDENTIFICADAS:

A. API calls excesivas en build_home():
   build_home() → _menu_routes() → api.collection('web-menu-bar')
                 → api.route(route) para la PRIMERA ruta
                 → _screen_from_page() que para cada rail sin items
                   llama api.collection(id) ADICIONAL

   Esto significa: 1 (menu) + 1 (route) + N (collections por rail) requests

B. Sin caché en repository:
   - build_home() llama api.route() cada vez que abres la home
   - _menu_routes() tiene caché en add_menu_items() pero repository.py
     NO usa mem_cache
   - Cada vez que navegas a Home se refetcha TODO

C. HBO Max API ya es lenta de por sí (comparada con Disney+ GraphQL)

SOLUCIÓN:
- Agregar @mem_cache.cached() a build_home() (30-60 seg)
- Agregar @mem_cache.cached() a _menu_routes() en repository.py
- Agregar @mem_cache.cached() a build_movies_home() y build_series_home()
- cacheToDisc=False en algunas operaciones reduce I/O
